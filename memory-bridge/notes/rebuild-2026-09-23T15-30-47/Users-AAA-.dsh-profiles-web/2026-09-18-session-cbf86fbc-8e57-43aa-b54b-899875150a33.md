# web — 2026-09-18

### 修复 dsh 插件安装失败：根因是 git URL 重写漏了 `git+ssh://` 且 github.com 直连不通

**问**：安装 `https://github.com/NanmiCoder/dsh-agent-teams.git` 到 profile `web` 时 pnpm 报 `Host key verification failed` / exit 128，要求诊断并修复后重装。

**做**：
- 定位报错 commit `e22bd19af7d27e0f7302061808d0cbd7dc9b0914` 实际属于 `@deepseek-ai/dsh-security-audit`（走 `github:omdsh-dev/...`），而非目标插件；`@nanmicoder/dsh-agent-teams` 走 npm registry（0.1.20），是前者失败导致整批 install 回滚。
- 查明 pnpm 把 `github:` 展开为 `git+ssh://git@github.com/...`，而 `C:\Users\AAA\.gitconfig` 原有 `insteadOf` 只覆盖 `git@github.com:` 和 `ssh://git@github.com/`，漏了 `git+ssh://`；且机器上无 `C:\Users\AAA\.ssh` 目录，必然 host key 失败。
- 实测连通性：`github.com:443` 超时，`codeload.github.com` / `api.github.com` / `registry.npmjs.org` 通；本机代理 `127.0.0.1:7897` 可用但 git 不读 Windows 系统代理。
- 修改 `C:\Users\AAA\.gitconfig`：新增 `insteadOf = git+ssh://git@github.com/`，并加 `[http "https://github.com/"] proxy = http://127.0.0.1:7897`。原文件备份为 `C:\Users\AAA\.gitconfig.bak-20260918-215327`。
- 未改动 `package.json` / `pnpm-lock.yaml` / `pnpm-workspace.yaml`；原始快照备份在 `C:\Users\AAA\.dsh\profile-backups\web-20260918-215348\`。
- 验证：原失败命令 `git -c core.longpaths=true fetch --depth 1 origin e22bd19...` exit=0；干净临时目录 `pnpm add github:omdsh-dev/dsh-security-audit#e22bd19...` exit=0；profile `pnpm install` exit=0 且幂等；7 个依赖齐全含 `@nanmicoder/dsh-agent-teams@0.1.20`；`agent_teams_status` 正常响应证明插件已运行时加载。

**结论/决定**：
- 目标插件本身没问题，无需升级（0.1.20 = 仓库 main = registry 最新）。
- dsh 提示的 "add the exact key pnpm printed above under allowBuilds" 是**误报**：`dsh/lib/plugin-Ddi42qoW.js:125` 只要参数含 `github:`/`.git` 就无条件打印，pnpm 从未打印该键，且 `dsh-security-audit` 无 `prepare` 脚本，应忽略。
- 不建议把 agent-teams 改为直接跟踪 GitHub 仓库（会引入每次安装都需 git 的依赖）。
