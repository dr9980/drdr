**问**：插件安装失败，报错 "dsh plugin add 报告成功，但 profile 未新增任何依赖（安装未生效）"，目标 `https://github.com/NanmiCoder/dsh-agent-teams.git`，要求诊断并重新安装。

**做**：
- 定位报错来源：`@linxin666/dsh-client-ui-plugin-manager/lib/index.js:1406`，触发点在第 1559 行 `newDependency()` —— 只比较依赖**名字**，不比较 spec，因此对已存在的依赖名永远返回 `undefined`，必然误报"未新增任何依赖"；且该分支只 `return`、**不执行 rollback**（区别于 duplicate claim 分支），破坏性变更被留在磁盘上。
- 通过 GitHub API 查 commit `87c95c9` 的 git 树：有 `src/`、`tsconfig.json`、`tsdown.config.ts`，**无 `lib/`**（构建产物被 .gitignore 忽略）；包 `scripts` 只有 `build` 和 `prepublishOnly`，**无 `prepare`** → npm/pnpm 对 git 依赖只自动跑 `prepare`，永不触发构建；`files` 列了 `lib` 却没列 `src` → 装出来的包源码与产物双空，`import()` 报 `ERR_MODULE_NOT_FOUND`。
- 对照 npm registry 的 0.1.20 tarball：含 58 个 `lib/` 文件，完全可用。
